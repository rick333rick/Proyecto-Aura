# Aura Bistró & Grill - Proyecto Final Frontend Developer

Landing page comercial moderna y responsiva desarrollada para un restaurante de alta cocina, creada a partir del flujo de trabajo propuesto en la guía académica: generación inicial con IA, personalización integral, formulario validado y mejoras avanzadas con JavaScript interactivo.

---

## Fases del Proyecto

- **Fase 1 – Diseño con IA:** Estructuración y generación del concepto base.
- **Fase 2 – Personalización:** Adaptación al giro de **Restaurante**:
  - Paleta de colores cálida y elegante (dorado ámbar y fondos oscuros).
  - Selección de imágenes de alta resolución de gastronomía y ambiente.
  - Textos y propuestas de valor de alta cocina.
  - Tipografías *Playfair Display* y *Plus Jakarta Sans*.
  - Animaciones y efectos hover interactivos.
- **Fase 3 – Formulario Funcional:**
  - Campos: Nombre, Correo, Teléfono y Mensaje.
  - Validaciones: `required`, `minlength` y `email`.
- **Fase 4 – Mejora con JavaScript:**
  - Menú responsive con animación de hamburguesa.
  - Botón flotante para volver arriba (*Back to top*).
  - Validación personalizada en tiempo real con mensajes de error visuales.
  - Ventana modal interactiva de confirmación de reserva.

---

## Cómo Ejecutar

Basta con hacer doble clic en `index.html` para abrirlo en cualquier navegador web.

Alternativamente, puedes levantar un servidor local con Python:
```bash
python -m http.server 8080
```
Y abrir `http://localhost:8080` en el navegador.
